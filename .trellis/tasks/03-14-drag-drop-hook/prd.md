# 实现卡牌拖拽系统

## Goal
在 `space-21-game/src/hooks/useDragDrop.ts` 中实现卡牌拖拽 Hook。

## Requirements

### 状态管理
- isDragging, draggedCard, draggedFrom, position

### 方法
- startDrag, updateDragPosition, endDrag

### 交互逻辑
- 鼠标按下开始拖拽
- 鼠标移动更新位置
- 鼠标释放检测目标并移动卡牌

## Acceptance Criteria
- [ ] Hook 实现完成
- [ ] 拖拽状态管理正确
- [ ] TypeScript 类型完整

# 实现背包管理系统

## Goal
在 `space-21-game/src/utils/inventoryManager.ts` 中实现背包管理功能。

## Requirements

### 核心函数
1. addCardToInventory - 添加卡牌（自动堆叠）
2. removeCardFromInventory - 移除卡牌
3. calculateTotalWeight - 计算总重量
4. canAddCard - 检查是否可添加
5. splitCardStack - 分离堆叠

### 技术要求
- 不可变数据操作
- 完整 TypeScript 类型
- 边界情况处理

## Acceptance Criteria
- [ ] 所有函数实现完成
- [ ] 不修改原对象
- [ ] TypeScript 类型检查通过

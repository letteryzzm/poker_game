# 技能卡系统 v2.0

## 目标
实现 Space-21 游戏的技能卡系统，包括技能卡数据结构、背包管理和核心技能卡效果。

## 需求

### 1. 技能卡数据层
- 创建 SkillCard 类型定义
- 配置 8 种技能卡数据（5战斗+3增益）
- 更新 Inventory 接口支持技能卡

### 2. 状态管理
- playerStore 添加技能卡管理方法
- gameStore 添加技能卡使用逻辑
- 实现冷却机制（每局结束冷却-1）

### 3. 核心技能卡效果（必须实现）
- **透视眼**：查看庄家底牌 3 秒
- **保险**：输了只扣 50% 下注
- **双倍奖励**：赢了获得双倍星币

### 4. UI 组件
- SkillCard 组件（单个卡牌）
- SkillCardBar 组件（游戏快捷栏）
- InventoryModal 组件（背包弹窗）

## 验收标准
- [ ] 技能卡类型和配置完整
- [ ] 3 种核心技能卡在游戏中正常工作
- [ ] 冷却机制正确更新
- [ ] 背包界面可以查看技能卡
- [ ] 无 lint/type 错误

## 技术约束
- 使用 Zustand 管理状态
- 使用 Framer Motion 做动画
- 遵循现有代码风格

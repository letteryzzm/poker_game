## 🎨 UI元素素材包

### 1. 按钮组（6个）

```
按钮类型：
1. 主要按钮（Hit/Stand/确认）
2. 次要按钮（取消/返回）
3. 危险按钮（丢弃/退出）
4. 成功按钮（领取奖励）
5. 禁用按钮（灰色状态）
6. 高亮按钮（推荐操作）

设计要求：
- 风格：科幻圆角矩形
- 尺寸：200×60px（可缩放）
- 状态：正常、悬停、按下、禁用
- 效果：发光边框、渐变背景
- 格式：PNG透明底

技术要求：
- 每个按钮提供4种状态
- 总计24张图片
- 命名规范：btn_[type]_[state].png

关键词：sci-fi button, glowing border, gradient background, rounded rectangle, futuristic UI, neon effect
```

### 2. 图标组（10个）

```
图标列表：
1. 星币图标（💰）- 32×32px
2. HP图标（❤️）- 32×32px
3. 背包图标（🎒）- 32×32px
4. 设置图标（⚙️）- 32×32px
5. 地图图标（🗺️）- 32×32px
6. 商店图标（🏪）- 32×32px
7. 任务图标（📋）- 32×32px
8. 音量图标（🔊）- 32×32px
9. 关闭图标（❌）- 32×32px
10. 确认图标（✅）- 32×32px

设计要求：
- 风格：线性图标 + 发光效果
- 颜色：蓝色/紫色发光
- 格式：PNG透明底
- 提供2倍尺寸版本（64×64px）

关键词：sci-fi icons, glowing effect, line style, blue purple neon, futuristic symbols
```

### 3. 装饰元素（5个）

```
装饰类型：
1. 边框装饰（卡牌边框）- 250×360px
2. 角落装饰（UI四角）- 64×64px
3. 分隔线（横向）- 800×4px
4. 光效（背景光晕）- 512×512px
5. 粒子效果（星星点点）- 32×32px

设计要求：
- 风格：科幻发光效果
- 颜色：蓝色/紫色/金色
- 格式：PNG透明底
- 可平铺或重复使用

关键词：sci-fi decorations, glowing borders, corner ornaments, light effects, particle effects, neon style
```

## 🎨 统一风格指南

**色彩方案**：
- 主色：深蓝 #1A1A2E
- 辅色：紫色 #7B68EE
- 强调色：蓝色 #4A90E2
- 成功色：绿色 #4CAF50
- 警告色：橙色 #FF9800
- 危险色：红色 #F44336

**视觉风格**：
- 科幻太空主题
- 霓虹灯发光效果
- 深色背景为主
- 圆角设计（10-20px）
- 渐变和光效

**技术规范**：
- 所有PNG使用透明底
- 保持一致的分辨率（72 DPI用于屏幕显示）
- 文件命名规范：[类型]_[名称]_[尺寸].png
- 示例：bg_tutorial_1920x1080.png

## 📦 六、批量生成建议

### 6.1 优先级排序

**P0 - 立即需要（Week 2）**：
- 扑克牌面 52张 + 牌背 1张
- 基础资源卡 10张（铁矿、金矿、能量棒等）
- 新手矿区背景 1张

**P1 - 第二批（Week 3）**：
- 剩余资源卡 10张
- 其他场景背景 3张
- 其他NPC头像 3张

**P2 - 优化阶段（Week 4）**：
- 装饰元素
- 特效素材
- 额外变体

### 6.2 批量生成技巧

1. **使用一致的 Prompt 结构**
   - 保持风格统一
   - 使用相同的关键词
   - 固定尺寸和格式

2. **分类批量生成**
   - 同一天生成同类素材
   - 保持风格一致性
   - 便于后期调整

3. **版本管理**
   - 保存所有 Prompt
   - 记录生成参数
   - 保留原始文件

4. **质量检查**
   - 检查尺寸是否正确
   - 验证透明背景
   - 确认风格统一

## 🎯 七、使用指南

### 7.1 如何使用这些 Prompt

1. **复制 Prompt 到 AI 绘画工具**
   - Lovart
   - Midjourney
   - Stable Diffusion
   - DALL-E 3

2. **根据工具调整**
   - 某些工具可能需要简化 Prompt
   - 调整参数以获得最佳效果
   - 多次生成选择最佳结果

3. **后期处理**
   - 使用 Photoshop 或 Figma 调整
   - 确保尺寸精确
   - 优化文件大小

### 7.2 常见问题

**Q: 生成的图片尺寸不对怎么办？**
A: 使用图片编辑工具调整到精确尺寸，保持比例。

**Q: 风格不统一怎么办？**
A: 在 Prompt 中强调 "consistent with previous cards" 或使用相同的 seed。

**Q: 透明背景没有生成？**
A: 后期使用工具移除背景，或在 Prompt 中强调 "transparent background, no background"。
